# Arduino-Prototypes

## Overview
A collection of Arduino projects and hardware prototypes. Each directory contains the source code, component list, and wiring details for individual builds.

### Project Index
| Directory | Description | Core Components |
|-----------|-------------|-----------------|
| [`calculator/`](./calculator) | Basic arithmetic calculator with physical input and visual output. | Arduino Uno R4 Minima, 4x4 Matrix Keypad, 0.96" I2C OLED (SSD1306) |
